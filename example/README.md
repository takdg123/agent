# Agent System Examples

This directory contains example scripts demonstrating how to use the Agent system.

## Files

- **`agent_example.py`** - Basic demonstration of the Agent system
  - System initialization
  - Component status checking
  - Daily report generation
  - PDF analysis examples

## Usage

```bash
# Run the basic example
cd ~/agent
python example/agent_example.py

# Or run from the example directory
cd ~/agent/example
python agent_example.py
```

## What the Example Shows

1. **System Initialization** - How to create and initialize the Agent system
2. **Component Status** - Checking the status of all system components
3. **Daily Report Generation** - Generating comprehensive research reports
4. **PDF Analysis** - Analyzing individual PDF files
5. **Error Handling** - How the system handles various error conditions

## Customization

You can modify the example to:
- Change the time range for reports (e.g., `hours_back=24` for 1 day)
- Analyze specific PDF files
- Test different configuration options
- Add your own custom analysis workflows
